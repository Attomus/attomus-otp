# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately and do not open a public issue for them.

Email [security@attomus.com](mailto:security@attomus.com). Include:

- a clear description of the issue
- affected versions or commit ranges
- reproduction steps or proof of concept
- suggested mitigation if known

We aim to acknowledge receipt within five business days. We will investigate and coordinate
remediation before any public disclosure. Please allow a reasonable remediation window before
publishing details.

## Scope

Reports concerning AttomusOTP's Swift or Kotlin implementations, published packages, release
artefacts, or documentation are in scope.

## Safe Harbour

Attomus will not pursue legal action against good-faith security research that avoids privacy
violations, service disruption, data destruction, and access beyond what is necessary to
demonstrate the issue.

We will publish an advisory for a confirmed vulnerability when disclosure helps users understand
their exposure or required action. Security fixes ship in the latest release. We support the
current release; update to stay covered.
