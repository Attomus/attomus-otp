# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately and do not open a public issue for them.

Send the report to the Attomus security contact through the private disclosure channel used
for product security reviews. Include:

- a clear description of the issue
- affected versions or commit ranges
- reproduction steps or proof of concept
- suggested mitigation if known

We will acknowledge receipt, investigate, and coordinate remediation before any public
disclosure.
