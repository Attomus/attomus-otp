# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately and do not open a public issue for them.

Email [security@attomus.com](mailto:security@attomus.com). Include:

- a clear description of the issue
- affected versions or commit ranges
- reproduction steps or proof of concept
- suggested mitigation if known

We aim to acknowledge receipt within five business days. We will investigate and coordinate
remediation before any public disclosure. Please allow a reasonable remediation window before
publishing details.
